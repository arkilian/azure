# Guia de Aprendizagem: Azure Fundamentals

## 📚 Bem-vindo ao Microsoft Azure!

Este guia foi criado para ajudá-lo a aprender os fundamentos do Microsoft Azure utilizando a documentação oficial da Microsoft Learn.

### 🎯 Sobre este Curso

**Master the basics of Azure: Fundamentals** é uma coleção de módulos de aprendizagem que cobre os conceitos essenciais do Azure, incluindo computação em nuvem, serviços do Azure, segurança, governança e muito mais.

**Link da Coleção Oficial:** https://learn.microsoft.com/en-us/collections/n6ga8m0jkgrwk

---

## 📋 Índice do Curso

### 1. Fundamentos de Cloud Computing e Azure

#### Módulo 1: Conceitos de Cloud Computing
- **O que é Cloud Computing?**
  - Definição e benefícios da computação em nuvem
  - Modelos de serviço: IaaS, PaaS, SaaS
  - Modelos de implantação: Público, Privado, Híbrido
  
- **Recursos:**
  - [Documentação: O que é Cloud Computing?](https://learn.microsoft.com/pt-br/azure/cloud-adoption-framework/get-started/what-is-azure)
  - [Conceitos básicos do Azure](https://learn.microsoft.com/pt-br/training/paths/azure-fundamentals/)

#### Módulo 2: Introdução ao Microsoft Azure
- **Visão Geral do Azure**
  - O que é o Microsoft Azure?
  - Serviços principais do Azure
  - Portal do Azure e ferramentas de gerenciamento
  
- **Recursos:**
  - [Portal do Azure](https://portal.azure.com)
  - [Documentação oficial do Azure](https://learn.microsoft.com/pt-br/azure/)

---

### 2. Principais Serviços do Azure

#### Módulo 3: Serviços de Computação
- **Azure Virtual Machines (VMs)**
  - Criação e gerenciamento de VMs
  - Tamanhos e tipos de VMs
  
- **Azure App Service**
  - Hospedagem de aplicações web
  - Escalabilidade automática
  
- **Azure Container Instances e Azure Kubernetes Service (AKS)**
  - Containers no Azure
  - Orquestração com Kubernetes
  
- **Azure Functions**
  - Computação serverless
  - Execução de código baseada em eventos

- **Recursos:**
  - [Documentação: Azure Compute](https://learn.microsoft.com/pt-br/azure/architecture/guide/technology-choices/compute-decision-tree)

#### Módulo 4: Serviços de Rede
- **Azure Virtual Network (VNet)**
  - Redes virtuais e sub-redes
  - Conectividade entre recursos
  
- **Azure Load Balancer e Application Gateway**
  - Distribuição de carga
  - Balanceamento de tráfego
  
- **Azure VPN Gateway e ExpressRoute**
  - Conectividade híbrida
  - Conexões seguras

- **Recursos:**
  - [Documentação: Azure Networking](https://learn.microsoft.com/pt-br/azure/networking/)

#### Módulo 5: Serviços de Armazenamento
- **Azure Storage Account**
  - Blob Storage (armazenamento de objetos)
  - File Storage (compartilhamentos de arquivos)
  - Queue Storage (filas)
  - Table Storage (armazenamento NoSQL)
  
- **Azure Managed Disks**
  - Discos para VMs
  - Tipos e níveis de desempenho
  
- **Recursos:**
  - [Documentação: Azure Storage](https://learn.microsoft.com/pt-br/azure/storage/)

#### Módulo 6: Serviços de Banco de Dados
- **Azure SQL Database**
  - Banco de dados relacional como serviço
  
- **Azure Cosmos DB**
  - Banco de dados NoSQL distribuído globalmente
  
- **Azure Database for MySQL e PostgreSQL**
  - Bancos de dados open source gerenciados
  
- **Recursos:**
  - [Documentação: Azure Databases](https://learn.microsoft.com/pt-br/azure/azure-sql/)

---

### 3. Segurança, Identidade e Governança

#### Módulo 7: Segurança e Identidade
- **Azure Active Directory (Azure AD / Entra ID)**
  - Gerenciamento de identidade e acesso
  - Autenticação e autorização
  
- **Azure Security Center**
  - Postura de segurança
  - Proteção contra ameaças
  
- **Azure Key Vault**
  - Gerenciamento de segredos, chaves e certificados
  
- **Recursos:**
  - [Documentação: Segurança do Azure](https://learn.microsoft.com/pt-br/azure/security/)

#### Módulo 8: Governança e Conformidade
- **Azure Policy**
  - Aplicação de políticas e conformidade
  - Governança de recursos
  
- **Azure Blueprints**
  - Templates de implantação com governança
  
- **Gerenciamento de Custos**
  - Azure Cost Management
  - Orçamentos e alertas
  
- **Recursos:**
  - [Documentação: Governança do Azure](https://learn.microsoft.com/pt-br/azure/governance/)

---

### 4. Gerenciamento e Monitoramento

#### Módulo 9: Ferramentas de Gerenciamento
- **Portal do Azure**
  - Interface web para gerenciar recursos
  
- **Azure CLI**
  - Linha de comando para automação
  
- **Azure PowerShell**
  - Scripts para gerenciamento
  
- **Azure Cloud Shell**
  - Shell baseado em navegador
  
- **Azure Resource Manager (ARM) Templates**
  - Infraestrutura como código
  
- **Recursos:**
  - [Documentação: Ferramentas de Gerenciamento](https://learn.microsoft.com/pt-br/azure/azure-resource-manager/)

#### Módulo 10: Monitoramento e Diagnóstico
- **Azure Monitor**
  - Monitoramento de aplicações e infraestrutura
  - Métricas e logs
  
- **Azure Log Analytics**
  - Análise de logs centralizada
  
- **Azure Application Insights**
  - Monitoramento de desempenho de aplicações
  
- **Recursos:**
  - [Documentação: Azure Monitor](https://learn.microsoft.com/pt-br/azure/azure-monitor/)

## 🚀 Como Começar

### Passo 1: Criar uma Conta Azure Gratuita
Você pode criar uma conta gratuita do Azure que inclui:
- $200 em créditos para usar nos primeiros 30 dias
- 12 meses de serviços gratuitos populares
- Mais de 55 serviços sempre gratuitos

**Link:** https://azure.microsoft.com/pt-br/free/

### Passo 2: Explorar a Documentação Oficial
A Microsoft oferece documentação completa em português:
- [Documentação do Azure](https://learn.microsoft.com/pt-br/azure/)
- [Microsoft Learn](https://learn.microsoft.com/pt-br/training/)

### Passo 3: Seguir a Coleção de Aprendizagem
Acesse a coleção oficial do curso:
- [Master the basics of Azure: Fundamentals](https://learn.microsoft.com/en-us/collections/n6ga8m0jkgrwk)

### Passo 4: Praticar no Portal do Azure
A melhor forma de aprender é praticando:
1. Acesse o [Portal do Azure](https://portal.azure.com)
2. Explore os diferentes serviços
3. Crie recursos de teste (dentro da camada gratuita)
4. Experimente as ferramentas de gerenciamento
