# Azure - Guia de Aprendizagem

## 📚 Aprender Microsoft Azure em Português

Este repositório contém materiais de estudo e guias para aprender Microsoft Azure utilizando a documentação oficial da Microsoft.

### 🎯 Conteúdo

- **[Guia Azure Fundamentals](GUIA_AZURE_FUNDAMENTALS.md)** - Guia completo para aprender os fundamentos do Azure baseado no curso oficial "Master the basics of Azure: Fundamentals"

### 🚀 Como Começar

1. Leia o [Guia Azure Fundamentals](GUIA_AZURE_FUNDAMENTALS.md) para uma visão completa do curso
2. Crie sua [conta gratuita do Azure](https://azure.microsoft.com/pt-br/free/)
3. Siga a [coleção oficial de aprendizagem](https://learn.microsoft.com/en-us/collections/n6ga8m0jkgrwk)
4. Pratique no [Portal do Azure](https://portal.azure.com)

### 📖 Recursos Oficiais

- **Documentação**: https://learn.microsoft.com/pt-br/azure/
- **Microsoft Learn**: https://learn.microsoft.com/pt-br/training/
- **Coleção do Curso**: https://learn.microsoft.com/en-us/collections/n6ga8m0jkgrwk

### 🎓 Certificação

Após completar os fundamentos, você pode buscar a certificação **AZ-900: Microsoft Azure Fundamentals**

- [Informações do Exame AZ-900](https://learn.microsoft.com/pt-br/certifications/exams/az-900/)

### 💡 Dicas

- Use a conta gratuita do Azure para praticar
- Dedique tempo regular ao estudo
- Junte-se à comunidade Azure
- Construa projetos práticos enquanto aprende
