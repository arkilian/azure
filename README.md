# Azure - Guia de Aprendizagem

## 📚 Aprender Microsoft Azure em Português

Este repositório contém materiais de estudo e guias para aprender Microsoft Azure utilizando a documentação oficial da Microsoft.

### 🎯 Conteúdo

#### Guia Principal
- **[Guia Azure Fundamentals](GUIA_AZURE_FUNDAMENTALS.md)** - Guia completo do curso com 10 módulos organizados

#### Recursos de Apoio
- **[Primeiros Passos](recursos/PRIMEIROS_PASSOS.md)** - Tutorial prático para criar sua conta e começar
- **[Glossário](recursos/GLOSSARIO.md)** - Dicionário de termos técnicos do Azure
- **[Links Úteis](recursos/LINKS_UTEIS.md)** - Coleção curada de documentação e recursos
- **[FAQ](recursos/FAQ.md)** - Perguntas frequentes e suas respostas
- **[Plano de Estudos](recursos/PLANO_DE_ESTUDOS.md)** - Template para organizar seu aprendizado

### 🚀 Como Começar

1. Leia o [Guia Azure Fundamentals](GUIA_AZURE_FUNDAMENTALS.md) para uma visão completa do curso
2. Crie sua [conta gratuita do Azure](https://azure.microsoft.com/pt-br/free/)
3. Siga a [coleção oficial de aprendizagem](https://learn.microsoft.com/en-us/collections/n6ga8m0jkgrwk)
4. Pratique no [Portal do Azure](https://portal.azure.com)
